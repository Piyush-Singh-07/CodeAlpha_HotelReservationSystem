# CodeAlpha_HotelReservationSystem

## Project Description
A console-based Java Hotel Reservation System that allows users to search available rooms, book rooms, cancel reservations, and view reservation details.

## Features
- Search available rooms
- Book a room
- Cancel a reservation
- View all reservations
- Supports Standard, Deluxe, and Suite room categories
- Simulates hotel reservation management

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Console-based Interface

## Project Structure
- `Room.java` – Manages room details and availability
- `Customer.java` – Stores customer information
- `Reservation.java` – Manages reservation details
- `Hotel.java` – Handles rooms and reservations
- `HotelReservationSystem.java` – Main program and user menu
